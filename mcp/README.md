# MCP: локальные настройки без секретов

`config.example.toml` — шаблон формата Codex CLI: серверы описываются в секциях `mcp_servers.<имя>`. Он намеренно закомментирован и не включает работающих адресов или учётных данных.

1. Скопируйте нужный фрагмент в локальный `~/.codex/config.toml` либо добавьте сервер командой `codex mcp add`.
2. Подставьте утверждённую команду или URL только на своей машине. Токены передавайте через переменную окружения (`bearer_token_env_var`), не через TOML.
3. Для PostgreSQL и ClickHouse создайте отдельные read-only роли с доступом лишь к нужным схемам/таблицам. Не добавляйте write/DDL/prod-подключения в общий профиль.
4. Локальные файлы с настройками держите вне репозитория или в путях из `.gitignore`.

Проверить зарегистрированные серверы можно командой `codex mcp list`. Файлы, добавленные в Git, должны оставаться шаблонами без паролей, токенов, приватных ключей, строк подключения и внутренних адресов.
